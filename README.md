流程展示
=
生成数据，通过该文档下的gre_md.py，生成了2w+份.md文件，每一份文件都通过提取专业气象数据特征得来

👇

分块：按照md文件的时次分块，将不同类型的气象特征汇总到一起，每个时间点都有以下几个大类：

①元数据，用于存储具体的时间点
②总览：是对该时间点下，气象状态的概括性文本
③细节：更加专业化，相较于总览具有更广，更深
④重要信息：一般意义上最为重要的气象特征

👇

嵌入：使用的BAAI/embeding_model/bge-large-zh-v1.5模型

👇

召回与重排：参考retriever.py,在分级索引的帮助下，能够极大的缩小与querry向量查询的范围，

同时为了让用户提问的句子更接近知识库中陈述句的表达，微调了一个小型的seq2seq模型，用来将疑问句转化成陈述句，见文件夹lora_s2s

👇

生成：挂载QWEN-code-7B模型，自动生成prompt，
结果显示RAG前模型有明显的不足：无法回答某个专业气象特征在某个时间点是多少，而温度这种常见气象指标则回答的不准（以ERA5数据为参考标准的话），并且还会出现幻觉，例如问他环流特征他会开始乱编，而RAG后能够减少幻觉，正确显示

=
项目里没有预载.nc文件（.nc文件常见于气象数据中，是一种网格化的数据），本文使用了1961-2021年间，长江流域内的气象数据，时间分辨率：3h 空间分辨率:25km、
